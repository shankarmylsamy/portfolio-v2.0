# Portfolio

A responsive personal portfolio starter built with React, TypeScript, and Vite.

## Get started

```sh
npm install
npm run dev
```

Open the local URL printed by Vite to preview the site.

## Customize

- Update the name, introduction, sections, and project entries in `src/App.tsx`.
- Replace the contact email and add links to your work and social profiles.
- Adjust the colors, typography, and responsive styles in `src/index.css` and `src/App.css`.
- Update the page title and description in `index.html`.

## Scripts

- `npm run dev` starts the development server.
- `npm run build` type-checks the app and creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
- `npm run lint` runs Oxlint.
